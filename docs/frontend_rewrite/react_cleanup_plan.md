# React UI — план повышения чистоты кода

**Срез:** 2026-07-27 · **Область:** `react-ui/` (~4 370 строк TSX, 20 компонентов)
**Статус кода:** прототип-грейд, работает корректно, старый UI не тронут.
**Цель плана:** довести до прод-грейда **без изменения поведения**, инкрементально.

---

## Принципы

1. **Ноль изменений поведения.** Каждый шаг — рефактор под зелёный `tsc --noEmit` и без визуальных регрессий.
2. **Инкрементально.** Никакого big-bang. Старый `app.css` и текущий React работают весь переход.
3. **Проверяемость.** После каждого пункта — `tsc` чистый + быстрый прогон затронутого экрана в живом preview.
4. **CSS Modules, не Tailwind.** Боль — «глобальный CSS, не видно мёртвого», её лечит скоупинг, а не утилитарные классы. (Обоснование — в конце.)

## Задачи

### 1. Общие форматтеры — `src/utils/format.ts`
**Что:** `fmtClock`, `fmtDateTime`, `fmtDate`, `n3` (число до 3 знаков), `pct`, `fmtTs` (epoch с авто-детектом сек/мс) продублированы в ~12 файлах.
**Как:**
- Создать `utils/format.ts` с одной реализацией каждого.
- Заменить локальные копии импортом. Удалить дубли.
**Готово когда:** ни в одном компоненте нет локального `toLocaleTimeString`/`toFixed(3)`/`padStart`; `tsc` зелёный.

### 2. Хук поллинга — `src/hooks/usePolling.ts`
**Что:** 7 ручных `setInterval` (streams 4с, probes 5с, feed 3с, preview-cadence, probe-status и т.д.) с повторяющимся cleanup.
**Как:**
```ts
usePolling(fn, ms, { enabled, immediate })  // сам чистит, останавливается при !enabled
```
- Перевести Video/Monitoring/ProbeSettingsModal на него.
**Готово когда:** нет голых `setInterval` в компонентах; поведение поллинга не изменилось.

### 3. Общие пустые/ошибочные состояния
**Что:** 11 инлайн `empty-state` / `chat-error`, визуально разнобойные.
**Как:**
- `components/shell/EmptyState.tsx` (иконка + заголовок + подсказка).
- `components/shell/ErrorBanner.tsx` (единый стиль ошибки).
- Заменить инлайны в Archive/Video/Monitoring/Settings.
**Готово когда:** ошибки и пустые состояния выглядят одинаково во всех разделах.

### 4. Затянуть типы на границах API
**Что:** 92 `any`, из них болезненные — `Promise<any>` в `probesApi.status`, `settingsApi.*`, части `agent.ts`.
**Как:**
- Описать интерфейсы ответов (`ProbeStatus`, `AuditEvent`, `LmCatalog` — часть уже есть).
- Заменить `any` на них; на честно-неизвестном оставить `unknown` + сужение.
- Цель — не «0 any», а **0 any на публичных сигнатурах api-слоя**.
**Готово когда:** в `src/api/*.ts` нет `Promise<any>`; `tsc` зелёный.

### 5. Setup CSS Modules + пилот
**Что:** разблокировать скоупинг.
**Как:**
- `src/vite-env.d.ts` → `/// <reference types="vite/client" />` (типы для `*.module.css`).
- Мелкий `cx()` (или `clsx`) для условных классов.
- **Пилот:** перевести `Dropdown` **или** `ToolTabs` на `Foo.module.css` — образец паттерна.
- `theme.css` остаётся глобальным (переменные), `app.css` не трогаем.
**Готово когда:** пилот-компонент на модуле, класс скоупится (`Foo_x__hash`), визуал 1:1.

### 6. Инкрементальная миграция CSS (фоново)
**Что:** растворить `app.css` по мере касания компонентов.
**Как (правило):** трогаешь компонент → выносишь его правила из `app.css` в колокейт `Component.module.css`, удаляешь из `app.css`. Общие keyframes/утилиты — оставить в глобальном слое или `:global`.
**Готово когда:** `app.css` пуст → удалить импорт. **Без дедлайна, по мере работы.**

### 7. Распил `AgentPanel` (594 стр / 19 useState)
**Что:** мешает streaming + sessions + skills + model + resize + UI.
**Как:**
- `useAgentStream` (SSE/стриминг + patchLast/patchAction).
- `useAgentSessions` (список/открыть/удалить/localStorage).
- `usePanelResize` (drag-ширина + persist).
- Панель остаётся вёрсткой + композицией хуков.
**Готово когда:** файл < ~300 строк, логика в хуках, поведение идентично.
**Риск:** средний — трогается стриминг агента; тестировать вживую.

### 8. Базовые тесты ключевых потоков
**Что:** ~0 покрытия UI.
**Как (минимум):**
- `utils/format` — юнит.
- Нормализация детекций (`normalizeDetection`, `detectionsFromResult`).
- Парс severity/gate у проб.
- Дымовой рендер каждого экрана (mount без падения).
**Готово когда:** `vitest` зелёный, покрыты нормализаторы данных.

## Явно вне области

- **Tailwind.** Много bespoke-анимаций/SVG (игра на Home, keyframes раскатов/испарения, blur, градиенты) — утилитарные классы тут дают налог, а не ускорение. Скоупинг решает реальную боль дешевле.
- **Big-bang переписывание CSS.** Только инкрементально (#6).
- **Смена стейт-менеджера** (Redux/Zustand). Локального `useState` + хуков (#7) достаточно для текущего масштаба.
