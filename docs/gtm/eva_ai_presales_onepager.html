Talk Tracks

Как объяснять без продажной пены

Три версии одного и того же продукта: для инженера, оператора и интегратора.

Это Flask/Python приложение с FAISS-backed visual search, CLIP/SigLIP/DINO embeddings, Luxriot snapshot/bookmark integration, OpenAI-compatible VLM pipeline, SQLite event storage и tool-calling агентом.

Streams -> embeddings/summaries -> detections/rollups -> agent tools -> Luxriot actions.
Heavy vision heads изолированы и профилируются отдельно через harness.
Мутации защищены admin token и preview-first flow в agent tools.

Система помогает искать события по описанию, следить за выбранными сценариями на живых камерах, получать сводки по потокам и быстро создавать bookmarks.

Видно, какие пробы включены, по каким каналам и с какими порогами.
ROI делает намерение пробы явным и проверяемым.
Сводки можно читать по уровням: batch, окно, час, длинный период.

EVA AI можно начинать как PoC рядом с Luxriot Evo: читать каналы и snapshots, отправлять bookmarks, хранить свой event/archive слой, затем углублять интеграцию.

Первый уровень интеграции: Luxriot HTTP API и bookmarks.
Следующий уровень: общие справочники каналов, зон и lifecycle событий.
Обратная связь операторов может стать материалом для тюнинга проб.

Engineering Honesty

Что важно проговорить заранее

Эти ограничения помогают удерживать доверие: проект сильнее выглядит, когда его не продают как магию.

Alpha PoCЭто рабочий exhibition PoC, а не сертифицированная safety/security-система.
GPU budgetDINO и Mask2Former нужно профилировать под конкретное железо; CLIP-only быстрее для первого запуска.
Prompt qualityVLM-сводки зависят от модели, промпта, sampling cadence и камеры.
Storage evolutionSQLite/JSON/файлы достаточны для PoC, но мультисайт потребует более формальной схемы.
Probe calibrationSemantic probes требуют калибровки на реальных камерах и обратной связи от операторов.
Bookmark hygieneCooldown/dedupe gates обязательны, иначе журнал событий быстро становится шумным.
