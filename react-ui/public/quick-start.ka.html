EVA AI 0.8.7 · საპილოტე დანერგვა

ოპერატორის მოკლე სახელმძღვანელო

Luxriot Evo-ს დაკავშირება, არხების აღწერების გაშვება, ზონდებისა და VLM გაფრთხილებების შექმნა, მტკიცებულებების შემოწმება და EVA Agent-თან მუშაობა.

EnglishქართულიLatviešu
დაიწყეთ აქედან. გახსენით http://<EVA-IP>:5000 და შედით ადმინისტრატორის მიერ გაცემული ანგარიშით. არხების ანალიზის დაწყებამდე დააკავშირეთ Luxriot Evo. ინტერფეისის ენა იცვლება განყოფილებაში Appearance; კამერების სახელები, მტკიცებულებები, მოდელის აღწერები და საუბრები ავტომატურად არ ითარგმნება.

1. Luxriot Evo-ს დაკავშირება

  1. გახსენით MENU, შემდეგ Settings → Luxriot.
  2. Base URL-ში მიუთითეთ Evo HTTP API-ის მისამართი, მაგალითად http://192.168.1.50:8080, შემდეგ შეიყვანეთ Evo-ს მომხმარებელი და პაროლი.
  3. დააჭირეთ Save settings. პაროლის ცარიელი ველი ნიშნავს „არსებული პაროლის შენარჩუნებას“ და არა მის წაშლას.
  4. ქვედა სტატუსის ზოლში დაელოდეთ LUXRIOT CONNECTED-ს და ნულზე მეტ არხს. მწვანე სტატუსი ნიშნავს, რომ EVA-მ ახალი მონაცემები მიიღო.
  5. თუ არხები არ ჩანს, შეამოწმეთ IP, API პორტი, ქსელური წვდომა და Evo-ს მომხმარებლის კამერების ნახვის უფლებები.
ყველა არხი ერთდროულად არ ჩართოთ. დაიწყეთ მცირე ჯგუფებით და აკონტროლეთ აღწერის დაყოვნება და GPU-ის დატვირთვა. PTZ-ის გადაადგილების შემდეგ EVA-ს ახალი ხედის დასადასტურებლად მოკლე სტაბილური ინტერვალი სჭირდება.

2. ძირითადი განყოფილებები

განყოფილებადანიშნულება
Archiveვიზუალური მტკიცებულების ძებნა დროით, არხით, ტექსტით ან სურათით. შედეგიდან შეგიძლიათ მეზობელი კადრებისა და Luxriot-ის საარქივო ვიდეოს გახსნა.
Stream summariesStream review აჩვენებს L0–L3 აღწერებს. Stream settings რთავს ან აჩერებს არხს და ხსნის prompt-ებისა და გაფრთხილებების პარამეტრებს.
Probesსწრაფი სემანტიკური ყურადღების სიგნალები რეგულარულად ინდექსირებულ კადრებზე; ზონდს შეუძლია Luxriot bookmark-ის შექმნაც.
Agentიკვლევს არქივს, აღწერებს, გაფრთხილებებს, ინციდენტებს და სისტემის მდგომარეობას. Operator ON-ის დროს აგენტს შეუძლია მხარდაჭერილი ეკრანების გახსნა.
ქვედა სტატუსის ზოლიაჩვენებს Luxriot-ის მონაცემების სიახლეს, ხელმისაწვდომ არხებს, აგენტის მდგომარეობასა და ზონდებს.

3. არხის აღწერების გაშვება

  1. გახსენით Stream summaries → Stream settings და აირჩიეთ არხი.
  2. თავდაპირველად დატოვეთ რეკომენდებული batch და cadence. მოძრაობის ან ყურადღების სიგნალის ზრდისას EVA-ს შეუძლია კადრების სიმჭიდროვის გაზრდა.
  3. დააჭირეთ Apply changes, შემდეგ Start summaries. Flush გამოიყენეთ მხოლოდ მაშინ, როცა არასრული batch დაუყოვნებლივ უნდა გაიგზავნოს.
  4. Stream review-ში აირჩიეთ არხი, დროის შუალედი და დონე: L0 დაკვირვებები, L1 15 წუთი, L2 ერთი საათი ან L3 რვა საათი. Auto შესაბამის სიღრმეს თვითონ ირჩევს.
როგორ წავიკითხოთ აღწერა. L0 არის ერთი ვიზუალური batch და მისი უშუალო VLM გადაწყვეტილება. L1–L3 ქვედა დონეებს აერთიანებს და დამოუკიდებელი ვიზუალური დაკვირვება არ არის. Burst ნიშნავს არხის ჩვეულებრივ დონეზე ძლიერ მოძრაობას. წარმომადგენლობით სურათზე დაჭერით გახსენით გაგზავნილი კადრები. BATCH_STATE_JSON მანქანურად წაკითხვადი მდგომარეობაა და ყოველდღიურ მუშაობაში მისი გახსნა საჭირო არ არის.

4. სემანტიკური ზონდის შექმნა

  1. გახსენით Probes და დააჭირეთ New probe.
  2. აირჩიეთ არხი და გამოიყენეთ ოპერატიული სახელი, მაგალითად „პატარა გემი ნავსადგურის შესასვლელთან“.
  3. Positive scene-ში აღწერეთ საძებნი ხილული სიტუაცია. Negative look-alike-ში აღწერეთ ყველაზე მსგავსი ნორმალური ხედი, რომელიც უნდა ჩაიხშოს. მაგალითი: small sailing craft crossing the harbour entrance და open water and breakwater with no nearby craft.
  4. თავდაპირველად დატოვეთ შემოთავაზებული Positive floor და Margin. ზღვრები შეცვალეთ მხოლოდ რეალური სწორი და მცდარი დამთხვევების შემოწმების შემდეგ.
  5. საჭიროების შემთხვევაში ჩართეთ Luxriot bookmark-ები და მიუთითეთ severity, cooldown და deduplication.
  6. ROI გამოიყენეთ მხოლოდ ფიქსირებული ხედისთვის. ერთი ROI სხვადასხვა PTZ preset-ზე ბრმად არ გადაიტანოთ.
ზონდის დამთხვევა ფაქტი არ არის. ის ყურადღებას ავიწროებს და შეიძლება კადრების სიხშირე გაზარდოს. უსაფრთხოებასთან დაკავშირებული დასკვნა ვიზუალურ მტკიცებულებაში ან VLM აღწერაში გადაამოწმეთ.

5. VLM გაფრთხილების შექმნა

  1. გახსენით Stream summaries → Stream settings, აირჩიეთ არხი და დააჭირეთ Prompts & alerts.
  2. Alerts-ში აღწერეთ ხილული კრიტერიუმები, მნიშვნელობა და საჭირო გამონაკლისები. გამოიყენეთ დაკვირვებადი მოქმედება, გეომეტრია და მოძრაობის მიმართულება; ნუ გამოიგონებთ ვინაობას ან განზრახვას.
  3. მაგალითი: HIGH: two vessels are converging on crossing trajectories near the harbour entrance. Do not alert on perspective-only overlap when motion history shows safe separation.
  4. თუ მოვლენა Evo-ში უნდა გამოჩნდეს, ჩართეთ bookmark-ები და შეარჩიეთ მოვლენის ხანგრძლივობის შესაბამისი cooldown.
  5. შეამოწმეთ გაფრთხილების badge, წარმომადგენლობითი და მეზობელი კადრები, ასევე bookmark-ის დრო. ბუნდოვანი კრიტერიუმი ტექსტში გაასწორეთ და მხოლოდ threshold-ს ნუ შეამცირებთ.
Stream და Alerts სხვადასხვა მიზანს ემსახურება. Stream prompt განმარტავს სცენის ინტერპრეტაციას; მონიტორინგისა და განგაშის კრიტერიუმები უნდა იყოს Alerts-ში.

6. არქივის ძებნა და ინციდენტი

  • Archive-ში აირჩიეთ არხები, მტკიცებულების წყაროები და დროის შუალედი. Text query სემანტიკურ ძებნას ასრულებს.
  • შედეგის გახსნით შეამოწმეთ მეზობელი კადრები. Play archive video Evo-სგან შესაბამის დროს ვიდეოს ითხოვს; მომზადებას შეიძლება რამდენიმე ათეული წამი დასჭირდეს.
  • Report incident ამზადებს ინციდენტს დასაწყისით, დასასრულით, თანმიმდევრული მტკიცებულებებითა და აღწერით. შენახვამდე ოპერატორმა ყველაფერი უნდა გადაამოწმოს.
  • ვიზუალურად მცდარი გაფრთხილებისთვის გამოიყენეთ Report false positive. უკუკავშირი ზონდებისა და გაფრთხილებების შემდგომი გამართვისთვის ინახება.

7. EVA Agent-თან მუშაობა

კარგ მოთხოვნაში მითითებულია არხი ან ჯგუფი, ზუსტი დროის შუალედი და საჭირო მტკიცებულება ან შედეგის ფორმა.

  • Show high and critical VLM alerts on Harbour Gate West during the last two hours. Include evidence timestamps.
  • Search the last three days for small sailing craft entering the harbour. Show the six strongest visual matches.
  • Build an incident report around this alert, including the first approach, closest point, and final separation.
  • Check stream health for the selected eight channels and list coverage gaps without guessing what happened during missing video.
Operator ON აგენტს მხარდაჭერილ ეკრანებზე ნავიგაციის უფლებას აძლევს; Operator OFF ამას ბლოკავს. მოსთხოვეთ აგენტს დაკვირვებული მტკიცებულების, დასკვნისა და დაფარვის ხარვეზების მკაფიო გამიჯვნა. ინსტრუმენტის გამოძახება ადასტურებს, რომ ძებნა შესრულდა, მაგრამ არა იმას, რომ საბოლოო ტექსტის ყველა მტკიცება ჭეშმარიტია.

8. ცვლის დაწყებამდე სწრაფი შემოწმება

  1. Luxriot მწვანე ხდება მხოლოდ ახალი მონაცემების მიღების შემდეგ.
  2. საჭირო არხები ჩანს და არჩეულ არხს მიმდინარე preview აქვს.
  3. სატესტო არხი L0 აღწერას ქმნის კონფიგურირებული მაქსიმალური batch-window-ის ფარგლებში.
  4. სატესტო ზონდი მიმდინარე კადრებს აჩვენებს და მისი ჩართვა/გამორთვა შესაძლებელია.
  5. არქივის ძებნა ნამდვილ სურათს აბრუნებს; Evo playback სწორ დროსთან ახლოს ვიდეოს ხსნის.
  6. აგენტს შეუძლია არხების მდგომარეობის შემოწმება და დაკარგული ვიდეოს პერიოდში მოვლენების არ გამოგონება.
